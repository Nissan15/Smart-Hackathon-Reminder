========================
PROJECT OVERVIEW
========================

This system is for a college where:

- Admin (Professor) uploads hackathons.
- Students register for hackathons.
- Students can track deadlines.
- System shows registration status.
- Dashboard shows reminders and statistics.

2. Student

========================
DATABASE DESIGN
========================

Create SQLAlchemy models:

User:
- id (Primary Key)
- name
- email (Unique)
- password (hashed)
- role (admin/student)

Hackathon:
- id (Primary Key)
- title
- description
- registration_deadline
- submission_deadline
- created_by (ForeignKey to User)

Registration:
- id (Primary Key)
- student_id (ForeignKey to User)
- hackathon_id (ForeignKey to Hackathon)
- timestamp
